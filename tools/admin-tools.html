🔬 Admin Tools

Research Portal — internal utilities. Runs entirely in your browser.

How this works: these tools generate SQL. Nothing is executed here — you copy the SQL and paste it into Supabase → SQL Editor to apply the change. Nothing leaves your browser.

Add a new institution

Before running the generated SQL, check what's already there: SELECT value, display_order FROM dropdown_options WHERE category='institution' ORDER BY display_order;

Add a co-researcher

Confirm exact IDs/strings in Supabase first: SELECT id, value FROM dropdown_options WHERE category='institution' and SELECT id, study_key FROM studies.

After running it in Supabase, send the plain password to the co-researcher — not the SQL, not the hash.

Grant a study to an existing co-researcher

Use this when a new study becomes relevant to someone already onboarded. Do not recreate the account — that loses their password and audit trail.

Password hasher only

For when you need just the hash — e.g. to reset a password via UPDATE, or to construct SQL manually. Output format: salt:hash (161 characters).
